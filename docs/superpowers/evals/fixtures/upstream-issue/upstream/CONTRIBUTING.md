# Contributing to hostspec

hostspec does not use an issue tracker or pull requests.

## Reporting bugs

Send bug reports to the mailing list at `hostspec-dev@lists.example.org`. The archive is at `https://lists.example.org/hostspec-dev/`; search it before you write.

A good report has:

- the hostspec version and the Node.js version;
- the smallest input that shows the problem, as a `node -e` one-liner or a short script;
- what you expected and what happened instead, with the full error message.

Plain-text mail only. Do not attach logs from your own systems; reduce them to the input that fails.

## Patches

Send patches made with `git format-patch` to the same list.
